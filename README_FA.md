# WeightSpace Lab | آزمایشگاه مدل‌های وزن‌باز

**محیط وب فارسی برای بررسی، تحلیل، ویرایش و ارزیابی مدل‌های هوش مصنوعی با وزن‌های باز**

WeightSpace Lab یک ابزار پژوهشی محلی است که امکان مشاهده ساختار مدل، بررسی Tensorها، دریافت تحلیل و برنامه آزمایش از یک مدل زبانی، اعمال تغییرهای کنترل‌شده روی وزن‌ها و مقایسه نسخه اصلی با نسخه ویرایش‌شده را فراهم می‌کند.

برنامه روی کامپیوتر اجرا می‌شود، اما تمام رابط کاربری آن در مرورگر است. می‌توان مدل را از Hugging Face Hub دریافت کرد، پوشه محلی Transformers را بارگذاری کرد یا یک checkpoint مستقل را بررسی کرد. معماری اختصاصی حراف ۲ نیز پشتیبانی می‌شود.

[English README](README.md) · [وب‌سایت](https://jahaniwww.com) · [کانال تلگرام Tarfandoon](https://t.me/Tarfandoon)

## امکانات اصلی

- دریافت مستقیم مدل از **Hugging Face Hub** با شناسه مخزن مانند `Qwen/Qwen2.5-0.5B-Instruct`.
- بارگذاری پوشه محلی Hugging Face شامل `config.json`، فایل‌های توکنایزر و وزن‌های تک‌فایلی یا چندبخشی.
- بررسی checkpointهای `.pt`، `.pth`، `.ckpt`، `.bin` و `.safetensors`.
- شناسایی خودکار معماری، وظیفه احتمالی، تنظیمات مدل، نام و شکل Tensorها و نقش تقریبی پارامترها.
- بررسی آمار وزن‌ها، توزیع، Embedding، Attention، MLP و پارامترهای نرمال‌سازی.
- تحلیل ساختاری و بررسی فعال‌سازی در معماری‌های پشتیبانی‌شده.
- دریافت گزارش جامع و برنامه اولویت‌بندی‌شده از مدل‌های زبانی سازگار با OpenAI API، از جمله Ollama.
- ویرایش کنترل‌شده وزن‌ها: Scale، Scale Slice، نویز محدود و Clamp.
- Snapshot، بازگردانی، Undo/Redo و ثبت تاریخچه تغییرات.
- خروجی گرفتن از مدل ویرایش‌شده در مسیر جداگانه.
- مقایسه قبل و بعد برای مدل‌های دارای موتور اجرای متنی.
- داشبورد فارسی راست‌چین، پوسته روشن و تاریک و تایپوگرافی وزیرمتن.

## مدل‌ها و قالب‌های پشتیبانی‌شده

| منبع مدل | قابلیت |
|---|---|
| Hugging Face Hub | مخزن عمومی و مخزن خصوصی/محدود با توکن دسترسی؛ فایل‌ها ابتدا روی دیسک محلی دریافت می‌شوند. |
| پوشه محلی Hugging Face | `config.json`، فایل‌های توکنایزر، `model.safetensors`، `pytorch_model.bin` و نسخه‌های چندبخشی به همراه index. |
| PyTorch checkpoint | فایل‌های `.pt`، `.pth`، `.ckpt` و `.bin` شامل `state_dict` یا ساختار checkpoint قابل استخراج. |
| SafeTensors | فایل مستقل `.safetensors`، با امکان استفاده از تنظیمات همراه در صورت وجود. |
| حراف ۲ | بارگذاری اختصاصی، تولید متن، بررسی فعال‌سازی، ویرایش و مقایسه قبل/بعد با استفاده از پیکربندی داخلی مدل. |

### تفاوت بررسی وزن با اجرای مدل

مدل‌های زبانی خودرگرسیو و مدل‌های متن‌به‌متن Hugging Face که از طریق Transformers شناسایی شوند، امکان تولید متن و آزمون قبل/بعد دارند. مدل‌هایی مانند Masked LM، طبقه‌بندها یا مدل‌های بینایی ممکن است قابل بارگذاری، بررسی و ویرایش باشند، اما تولید متن آزاد برای همه آن‌ها معنا ندارد.

اگر یک فایل وزن به‌تنهایی ارائه شود و پیکربندی، توکنایزر یا معماری اجرایی آن موجود نباشد، برنامه می‌تواند Tensorها را بررسی و ویرایش کند؛ ولی برای ارزیابی رفتاری به معماری و ورودی متناسب با همان مدل نیاز است.

## اجرای سریع در ویندوز

پیش‌نیاز: Python نسخه 3.10، 3.11 یا 3.12. نصب اولیه وابستگی‌ها و دریافت مدل از Hub به اینترنت نیاز دارد.

1. مخزن را دانلود یا Clone کن.
2. فایل `run.bat` را اجرا کن.
3. لانچر محیط مجازی می‌سازد، PyTorch نسخه CPU و وابستگی‌ها را نصب می‌کند و داشبورد را اجرا می‌کند.
4. مرورگر را در نشانی `http://127.0.0.1:8765` باز کن.
5. از داخل داشبورد پوشه محلی، شناسه Hugging Face یا پوشه checkpoint را انتخاب کن.

تا زمانی که از برنامه استفاده می‌کنی، پنجره ترمینال را باز نگه دار. بستن آن سرور محلی را متوقف می‌کند.

## اجرای سریع در لینوکس

```bash
chmod +x run.sh
./run.sh
```

اسکریپت محیط مجازی می‌سازد، PyTorch و وابستگی‌های پروژه را نصب می‌کند و داشبورد را در `http://127.0.0.1:8765` اجرا می‌کند.

## نصب دستی

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python -m uvicorn webapp.app:app --host 127.0.0.1 --port 8765
```

سپس نشانی `http://127.0.0.1:8765` را در مرورگر باز کن.

## دریافت مدل از Hugging Face

در قسمت Hugging Face Hub شناسه مخزن را وارد کن؛ برای مثال:

```text
Qwen/Qwen2.5-0.5B-Instruct
```

در صورت نیاز می‌توانی revision یا شاخه مشخص کنی. برای مخزن خصوصی یا محدود، توکن دسترسی Hugging Face را فقط در همان فرم وارد کن. توکن در فایل تنظیمات برنامه ذخیره نمی‌شود.

برنامه فایل‌ها را با `huggingface_hub` دریافت و معماری را با `transformers` بارگذاری می‌کند. گزینه `trust_remote_code` غیرفعال است؛ بنابراین مدل‌هایی که برای اجرا به کد Python سفارشی داخل مخزن نیاز دارند، اجرا نمی‌شوند.

برای مدل محلی، کل پوشه مدل را انتخاب کن. وزن‌های چندبخشی در صورت وجود فایل index و تمام shardها با سازوکار خود Transformers بارگذاری می‌شوند.

## تحلیل مدل و ویرایش وزن‌ها

پروفایل مدل با استفاده از config، معماری اعلام‌شده، metadata و الگوهای نام‌گذاری پارامترها ساخته می‌شود. توضیح نقش Tensorها بر اساس قراردادهای رایج معماری است و به‌تنهایی رفتار یادگرفته‌شده مدل را اثبات نمی‌کند.

تحلیل‌گر می‌تواند از یک نشانی OpenAI-compatible استفاده کند. برای نمونه، نشانی Ollama معمولاً به شکل `http://localhost:11434/v1` است. پرونده ارسالی به تحلیل‌گر شامل مشخصات مدل، فهرست Tensorها، شکل و نوع داده، توضیح نقش، خلاصه آماری، یافته‌های بررسی و نمونه‌های رفتاریِ در دسترس است. ماتریس‌های کامل و خام وزن‌ها به API فرستاده نمی‌شوند.

ویرایش‌ها ابتدا اعتبارسنجی می‌شوند و در Snapshot ثبت می‌شوند. فایل اصلی بازنویسی نمی‌شود؛ خروجی در پوشه یا آرشیو جداگانه ساخته می‌شود.

## ارزیابی قبل و بعد

برای مدل‌های متنی پشتیبانی‌شده می‌توان یک مجموعه پرامپت ثابت را روی نسخه اصلی و نسخه ویرایش‌شده اجرا کرد. برنامه متن پاسخ‌ها و معیارهای سطحی مانند نسبت تکرار n-gram، تنوع n-gram، طول پاسخ و آنتروپی خروجی را نمایش می‌دهد.

این معیارها صحت اطلاعات، توانایی استدلال یا کیفیت کلی مدل را اثبات نمی‌کنند. برای ارزیابی جدی باید از مجموعه آزمون متناسب با وظیفه، پاسخ مرجع و داوری انسانی یا معیار تخصصی استفاده کرد.

## ایمنی و محدودیت‌ها

- بارگذاری پوشه از مرورگر به‌صورت قطعه‌ای روی دیسک نوشته می‌شود و سقف فعلی هر بارگذاری ۶۴ گیگابایت است.

- سرور به‌صورت پیش‌فرض فقط روی `127.0.0.1` اجرا می‌شود. بدون افزودن احراز هویت، مجوز دسترسی و محدودیت درخواست، آن را روی شبکه عمومی منتشر نکن.
- فایل‌های PyTorch با `weights_only=True` بارگذاری می‌شوند؛ اجرای pickle برای بارگذاری آبجکت دلخواه فعال نیست.
- گزینه `trust_remote_code` برای مخازن Hugging Face غیرفعال است.
- مدل‌های بزرگ به RAM و فضای دیسک قابل‌توجه نیاز دارند. اجرای CPU می‌تواند کند باشد.
- فرمت‌های کوانتایز‌شده مانند GGUF، GPTQ و AWQ فعلاً برای ویرایش Tensor پشتیبانی نمی‌شوند.
- ویرایش LoRA/PEFT در این نسخه پشتیبانی نمی‌شود.
- نشانه آماری به‌تنهایی علت رفتاری را اثبات نمی‌کند. ویرایش وزن یک آزمایش است و بهبود را تضمین نمی‌کند.

## اجرای تست‌ها

```bash
python -m unittest tests.test_harraf_workspace tests.test_web_api -v
```

تست یکپارچه Hugging Face در صورت نصب بودن `transformers` اجرا می‌شود. سایر تست‌ها معماری حراف ۲، checkpoint عمومی، ویرایش، بازگردانی، خروجی و API وب را بررسی می‌کنند.
