# راهنمای فارسی تحلیل وزن‌های حراف ۲

## نقش وزن‌ها در معماری

| نام | نقش واقعی در کد حراف ۲ | نکته بررسی |
|---|---|---|
| `wte.weight` | embedding ورودی توکن‌ها | نرم ردیف‌ها را بررسی کن؛ از آن فراوانی توکن را نتیجه نگیر. |
| `head.weight` | سر پیش‌بینی واژگان | در مدل اصلی به `wte.weight` متصل است. |
| `blocks.N.ln1.weight` | RMSNorm پیش از attention | مقادیر scale را با خروجی مدل بسنج. |
| `blocks.N.ln2.weight` | RMSNorm پیش از MLP | تغییر کوچک هم می‌تواند توزیع فعال‌سازی را جابه‌جا کند. |
| `blocks.N.attn.q.weight` | Query projection | نرم را با لایه‌های هم‌نوع مقایسه کن. |
| `blocks.N.attn.kv.weight` | Key/Value projection | در حراف، K و V در یک ماتریس ذخیره می‌شوند. |
| `blocks.N.attn.proj.weight` | Attention output projection | نقش آن ترکیب خروجی سرهای attention است. |
| `blocks.N.attn.tree_slope` | شیب جریمه ساختار درختی | از softplus آن در attention استفاده می‌شود. |
| `blocks.N.mlp.w1.weight` | شاخه اول SwiGLU | با w3 دروازه‌گذاری می‌شود. |
| `blocks.N.mlp.w3.weight` | شاخه گیت SwiGLU | تغییر آن می‌تواند رفتار MLP را عوض کند. |
| `blocks.N.mlp.w2.weight` | خروجی SwiGLU | فضای مخفی را به d_model برمی‌گرداند. |
| `blocks.N.mem.query.weight` | Query حافظه | برای بازیابی اسلات‌ها استفاده می‌شود. |
| `blocks.N.mem.keys` | کلیدهای حافظه | دو نیمه بردار Query را آدرس‌دهی می‌کنند. |
| `blocks.N.mem.values.weight` | جدول محتوای حافظه | هر توکن تنها بخشی از اسلات‌ها را می‌خواند. |
| `blocks.N.mem.hits` | بافر شمارش خواندن حافظه | بافر است و پارامتر trainable نیست. |
| `parser.*` | شبکه پیش‌بینی فاصله نحوی | خروجی آن روی ساختار درختی و attention اثر دارد. |
| `ln_f.weight` | RMSNorm نهایی | پیش از head اجرا می‌شود. |

## معنی شاخص‌ها

- **میانگین، انحراف معیار، کمینه، بیشینه و نُرم:** از نمونه‌ای منظم از مقادیر تنسر محاسبه می‌شوند تا تحلیل تنسرهای بزرگ حافظه زیادی نخواهد.
- **نسبت صفرها:** با پیمایش کامل تنسر محاسبه می‌شود.
- **NaN/Inf:** شمارش دقیق روی تمام عناصر تنسر انجام می‌شود، نه فقط نمونه نمودار.
- **Repeated trigram ratio:** سهم سه‌گرم‌های تکراری در متن تولیدی.
- **Trigram diversity:** سهم سه‌گرم‌های یکتا.
- **Mean entropy:** آنتروپی توزیع احتمال توکن بعدی حین تولید.

## روش درست آزمایش

۱. یک مجموعه پرامپت ثابت و متنوع بساز.
۲. مدل اصلی را اجرا و خروجی‌ها را ذخیره کن.
۳. فقط یک خانواده وزن را با تغییر کوچک و مشخص ویرایش کن.
۴. همان پرامپت‌ها را با همان decoding اجرا کن.
۵. خروجی‌ها را از نظر صحت، انسجام، تکرار، طول و تنوع مقایسه کن.
۶. فقط وقتی چند معیار مستقل بهبود را نشان دادند، تغییر را نگه دار.

## چرا صرف آمار وزن‌ها کافی نیست؟

وزن‌ها رفتار را به‌صورت غیرمستقیم تعیین می‌کنند. نام Tensor و اندازه آن نشان نمی‌دهد کدام پاسخ اشتباه است یا کدام تغییر به رفع آن کمک می‌کند. معیارهای آماری برای پیدا کردن نقطه شروع مفیدند؛ تشخیص رفتاری به اجرای مدل و آزمون نیاز دارد.
